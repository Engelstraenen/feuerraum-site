# FEUERRAUM Neubau 26.11.2026 – 3 Storyboards (Prompts)

Kernleistung: Kamin- und Ofenstudio, das Kaminöfen, Pelletöfen, Gaskamine und Speicheröfen verkauft, berät und mit eigenen Ofenbauern einbaut (Ausstellung mit brennenden Öfen, Einbau, Abnahme, Wartung).
Name bleibt FEUERRAUM (kein -WERK).

## Inspiration (nur Technik, nichts 1:1)
- getlayers `hearth-embers` (Funken/Glut-Partikel, Cursor zieht sie) → SB3 Partikel-Brücken
- getlayers `layer-stack` + `artefakt` (Explosionsansicht, Haarlinie von Karte zur Schicht) → SB2
- getlayers `fluted-veil` (warmes Glühen hinter geriffeltem Glas) → SB1 Frost-/Glasfläche
- getlayers `kimi` (heiße Spitze kühlt zur Linie, Faden durch die Seite) → SB1 Thermometer-Faden
- motionsites `forge-gate` (riesiges Wort hinter Vordergrund-Freisteller, Kamerafahrt-Video zwischen Zuständen) → SB3
- motionsites `particle-self` (Scroll-3D-Partikel) → SB3 Glut wird Diagramm
